Плагін ATAK — ICU NG

Відеотрансляція для ATAK: відео та аудіо з камер пристрою (задньої, передньої
або USB/UVC) на відеосервер RTSP, RTSPS або SRT з телеметрією KLV MISB ST 0601,
з оголошенням на карті, щоб інші користувачі ATAK могли відкрити її зі свого
списку відео (Video list). Заміна TAK ICU, інтегрована безпосередньо в ATAK.

Посібник користувача: в ATAK, Налаштування → Параметри інструментів →
Специфічні параметри інструментів → ICU NG (джерело: docs/user_manual/).

ПРИЗНАЧЕННЯ ТА МОЖЛИВОСТІ

ICU NG дає змогу оператору транслювати зображення з камери пристрою без виходу з
ATAK і без необхідності щоразу вручну налаштовувати трансляцію в іншому
застосунку. Трансляція називається позивним оператора й оголошується через
менеджер відеоз'єднань ATAK, тож решта команди може переглядати її безпосередньо
з ATAK.

- Кнопка REC на карті: натискання для запуску/зупинки зі збереженими
  налаштуваннями, тривале натискання для панелі налаштувань, тривале натискання
  з перетягуванням для переміщення вздовж правого краю.
- Панель налаштувань із живим попереднім переглядом: камера, протокол,
  URL-адреса сервера (введена вручну або зчитана з QR-коду), парольна фраза та
  шифрування SRT, якість (роздільна здатність, fps, бітрейт, адаптивний
  бітрейт, мікрофон).
- MISB ST 0601 KLV через RTSP/RTSPS щосекунди: координати й висота сенсора,
  азимут і кут місця камери (сенсор вектора обертання), поле зору, центр кадру
  на місцевості (дані висот ATAK), позивний.
- Конус поля зору сенсора на власному маркері під час трансляції.
- Кнопка трансляції в радіальному меню власного маркера.

Фонова трансляція. Плагін працює в процесі ATAK, а єдиний сервіс переднього плану ATAK має
тип "location", тому Android припиняє доступ плагіна до камери під час вимкнення
екрана. Щоб продовжувати трансляцію з вимкненим екраном, захоплення відео може
виконуватися додатковим супутнім застосунком ICU NG Capture (каталог capture/ у
репозиторії вихідного коду; звичайний застосунок Android, що не є частиною цього
подання), який утримує сервіс переднього плану (foreground service) камери/мікрофона.
Плагін залишається повноцінним інтерфейсом користувача й керує застосунком; без
встановленого застосунку плагін транслює самостійно, але тільки на передньому
плані.

СТАН ПРОЄКТУ

Версія 1.0. Перевірено на ATAK-CIV 5.8.0.7 (збірка для розробників): емулятор
(Android 14) для кожної функції, включно зі збіркою civRelease; протестовано в
польових умовах на планшеті Samsung (Android 16) під час трансляції через RTSP
на ретранслятор MediaMTX через VPN. Ще не перевірялося на реальному обладнанні:
USB-камера (UVC).

Підготовлено для подання стороннім розробником на tak.gov.

НЕОБХІДНІ ПОРТИ

(Це важливо для ATO, мережевої взаємодії та безпеки)

  Лише вихідні й тільки під час трансляції оператора на єдиний налаштований
  оператором відеосервер (URL-адреса, введена в панелі або зчитана з QR-коду):

  - RTSP:  TCP на RTSP-порт сервера (за замовчуванням у MediaMTX: 8554).
  - RTSPS: TCP + TLS на RTSPS-порт сервера (за замовчуванням у MediaMTX: 8555).
  - SRT:   UDP на SRT-порт сервера (за замовчуванням у MediaMTX: 8890).

  Жодних вхідних портів і відкритих сокетів для прослуховування. Жодного
  власного трафіку до або від сервера TAK: трансляція оголошується як
  відеоз'єднання через власні API ATAK і передається ATAK у CoT власного
  маркера. Під час відсутності трансляції нічого не надсилається; за відсутності
  мережі плагін просто не може підключитися.

  Локальний IPC із супутнім застосунком ICU NG Capture, якщо встановлено: запуск
  активностей (start/stop) і підключений сервіс AIDL (статус, поверхня
  попереднього перегляду, пакети KLV). Застосунок приймає виклики виключно від
  пакета ATAK.

НЕОБХІДНЕ ОБЛАДНАННЯ

  Пристрій Android, що підтримується ATAK-CIV 5.8, з камерою. Дозволи на
  використання камери та мікрофона (для ATAK або для ICU NG Capture, якщо

_________________________________________________________________
ПІДТРИМУВАНЕ ОБЛАДНАННЯ

  Вбудовані камери пристрою. Камери класу USB Video Class (UVC) через USB OTG.
  Відеосервер, що підтримує публікацію RTSP/RTSPS/SRT, наприклад MediaMTX або
  raytheonbbn/tak-video-restreamer.

_________________________________________________________________
КОМПІЛЯЦІЯ

  Стандартна збірка плагіна ATAK. Вкажіть sdk.path у local.properties на
  розпакований ATAK CIV SDK, після чого виконайте:

      ./gradlew assembleCivDebug
      ./gradlew assembleCivRelease

  ext.ATAK_VERSION у app/build.gradle вибирає цільову версію ATAK. Проєкт містить
  два модулі: app (плагін) і rootencoder-rtsp (див. нижче). У репозиторії
  вихідного коду міститься третій модуль — capture (супутній застосунок), якщо він
  наявний; він не потрібен для збірки плагіна.

ПРИМІТКИ ДЛЯ РОЗРОБНИКІВ

  - Трансляція побудована на RootEncoder 2.8.1 (pedroSG94, Apache-2.0),
    StreamBase API. rootencoder-rtsp/ є копією модуля rtsp із RootEncoder,
    модифікованою для оголошення та передачі KLV-доріжки (RFC 6597,
    application/smpte336m) поруч із відео та аудіо; див. rootencoder-rtsp/NOTICE.md.
    Застосунок використовує цей модуль замість опублікованого артефакту rtsp.
  - USB-камери: UVCAndroid 1.0.13 (herohan). Його нативний код викликає методи
    Java за назвою, звідси правила keep у proguard.
  - Декодування QR: ZXing core.
  - Налаштування зберігаються в стандартних конфігураціях ATAK (ключі icung.*),
    тому кнопка REC може запускати трансляцію навіть без попереднього відкриття
    панелі.
  - versionCode визначається на основі PLUGIN_VERSION та ATAK_VERSION (а не з
    git), тому збірки з цього архіву мають коректний versionCode.
  - Інтерфейс супутнього застосунку: app/src/main/aidl та CaptureLink.java з
    боку плагіна; ті самі файли AIDL у застосунку.
