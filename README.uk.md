## 📌 Огляд

**ICU NG** — це сучасна пряма заміна застарілої утиліти *TAK ICU*, інтегрована безпосередньо в ATAK як повноцінний плагін. Вона дозволяє оператору в польових умовах транслювати відео та аудіо в реальному часі зі вбудованих камер пристрою (основна/фронтальна) або зовнішніх USB-джерел (UVC) безпосередньо на відеосервери **RTSP, RTSPS (TLS) або SRT**.

Потоки маркуються позивним (*callsign*) оператора та автоматично анонсуються через стандартний менеджер відеоз'єднань ATAK (`<__video>` CoT). Робоча зона камери динамічно відображається на картах побратимів із проєктуванням конуса огляду сенсора та кутів кадру на місцевість.

```
       [ Камера пристрою / USB UVC ]
                     │
                     ▼
         ┌───────────────────────┐
         │     Плагін ICU NG     │ ◄─── Телеметрія (Вектор обертання, GPS, рельєф)
         │ (або супутній додаток)│ ───► Ін'єкція KLV MISB ST 0601 / ST 0902 (2 Гц)
         └───────────────────────┘
                     │
      ┌──────────────┴──────────────┐
      ▼ (RTSP / RTSPS / SRT)        ▼ (Анонс CoT Відео)
  ┌───────────────────────┐   ┌───────────────────────┐
  │ MediaMTX / Restreamer │   │      TAK Server       │
  └───────────────────────┘   └───────────────────────┘
              │                           │
              └──────────────┬────────────┘
                             ▼
              [ Віддалені клієнти ATAK / КП ]
           (Потоки з проекцією кадру на карту)
```

## 🎯 Основні можливості

### 1. Тактичний інтерфейс без зайвих дій
* **Кнопка REC на карті:** Натискання для запуску/зупинки зі збереженими налаштуваннями. Тривале натискання відкриває панель швидких налаштувань; перетягування переміщує її вздовж краю екрана.
* **Інтеграція в радіальне меню:** Запуск і контроль трансляцій безпосередньо з радіального меню власного маркера.
* **Налаштування за QR-кодом:** Швидке зчитування адрес серверів, облікових даних і ключів шифрування SRT через камеру.

### 2. Відповідність стандартам НАТО / STANAG 4609 та MISB KLV
* **MISB ST 0601 та ST 0902:** Формує стандартизовані пакети телеметрії KLV із частотою **2 Гц** (відповідно до ST 1402):
  * Позиція платформи та еліпсоїдна висота (Tags 13, 14, 15).
  * Азимут, кут місця та відносний крен камери (Tags 5, 6, 7, 20).
  * Горизонтальне поле зору (Tag 16) та ширина цілі (Tag 22).
  * Проєктований центр кадру та координати кутів на місцевості (Tags 23–26).
  * Набір міток безпеки (MISB ST 0102, Tag 48) та ідентифікатор місії за замовчуванням (Tag 3).
  * Ідентифікатор MIIS Core (MISB ST 1204, Tag 94) зі стабільним UUID v5 для відстеження сенсора/платформи.
* **Мітки точного часу MISB ST 0604:** Вбудовані в заголовки SEI кожного кадру H.264/H.265.
* **Проєкція відео на місцевість:** Клієнти-одержувачі можуть накладати перспективу відео прямо на карти висот ATAK.

### 3. Динамічний конус поля зору (FOV) сенсора
* На відміну від старих рішень, що малюють статичні конуси за курсом GPS, ICU NG розраховує **реальний вектор орієнтації камери**.
* Передає геометрію `<sensor>` у реальному часі через Cursor on Target (`REPORT_LOCATION`), демонструючи точну площу покриття на місцевості.

### 4. Фонова трансляція з вимкненим екраном
* В Android фоновий доступ до камери вимикається відразу після блокування екрана.
* ICU NG інтегровано з **ICU NG Capture**, супутнім сервісом (`capture/`), що має foreground-службу типу `camera|microphone`.
* Продовжуйте трансляцію із заблокованим екраном для збереження заряду батареї та світломаскування.

### 5. Мультипротокольність та високопродуктивне кодування
* Підтримувані протоколи: **RTSP** (RFC 2326), **RTSPS** (шифрування TLS) та **SRT** (Secure Reliable Transport із шифруванням AES і паролем).
* Кодеки: **H.264 (AVC) Main Profile** та **H.265 (HEVC)**.
* Постійна частота кадрів (CFR) та адаптивний бітрейт.
* Повна підтримка вбудованих об'єктивів і зовнішніх камер **USB UVC / OTG**.

## 🔒 Безпека та вимоги ATO (Authority to Operate)

Спроєктовано для суворих вимог тактичних і закритих відомчих мереж:

| Протокол | Стандартний порт | Напрямок | Шифрування / Транспорт | Призначення |
| :--- | :--- | :--- | :--- | :--- |
| **RTSP** | `8554` | Тільки вихідний | Відкритий TCP | Стандартне передавання відео |
| **RTSPS** | `8555` | Тільки вихідний | TLS поверх TCP | Захищена службова трансляція |
| **SRT** | `8890` | Тільки вихідний | UDP / AES-128/256 | Стійкий транспорт із низькою затримкою |

* **Жодних вхідних портів:** Відсутні відкриті сокети прослуховування на мобільному терміналі (EUD).
* **Повна робота в Air-Gap:** Без хмарних сервісів, без телеметрії, без несанкціонованих мережевих запитів.
* **Безпека локального IPC:** Взаємодія плагіна та супутнього додатка через AIDL суворо обмежена підписом пакета ATAK.

## 🛠️ Збірка та розробка

### Передумови
* Java 17 (OpenJDK / Temurin)
* Android SDK (API 34–36, Build Tools 34.0.0+)
* SDK ATAK-CIV (5.8.0.7+)

### Збірка
1. Вкажіть шлях до SDK у `local.properties`:
   ```properties
   sdk.path=/шлях/до/ATAK-CIV-5.8.0.7-SDK
   ```
2. Зберіть debug або release APK:
   ```bash
   ./gradlew assembleCivDebug
   ./gradlew assembleCivRelease
   ```
   *(Збірка супутнього додатка: `./gradlew :capture:assembleRelease`)*.
